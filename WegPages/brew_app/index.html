Hier findest du sowohl den direkten Link zur produktiven AiBrewGenius-Web-App als auch Hinweise, wie du das Flutter-Projekt lokal startest.

Live-Version (Server) Lokalen Web-Build öffnen

Der lokale Web-Build funktioniert nur, wenn in `flutter_brew_assistent/web/` ein aktuelles Build-Ergebnis liegt. Alternativ starte die Flutter-App wie unten beschrieben.

Flutter-Projekt lokal ausführen

  1. `cd flutter_brew_assistent`
  2. `flutter pub get` (falls noch nicht geschehen)
  3. `flutter run -d chrome` oder `flutter build web --wasm --base-href /brew_app/`

Nach dem Build liegt die Web-Version unter `flutter_brew_assistent/build/web/`. Du kannst sie mit jedem lokalen Webserver ausliefern oder über den oberen Button öffnen.
